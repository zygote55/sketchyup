Reproducible commands are in the evidence records. Native interaction, dialog,

for the merged implementation heads using Arch software GL. Core and arrangement
suites also passed ASan/UBSan. One million independent triangles rendered in
7.24 ms mean GPU-complete draw in the R002.b fixture; that excludes full-document
editing and compositor presentation. It is not the M9 latency result.

## Boundaries carried into implementation

- The planar adapter intentionally rejects unstable near-parallel cuts and only
  partitions isolated faces. M2 must propagate incident edge splits and validate
  finite-segment arrangements before delivering public topology editing.
- Edge identity, container, recovery, idempotency and UX amendment contracts are
  selected designs. Their corresponding production implementations remain later
  entries; the original v1 spike does not gain these guarantees from this gate.
- Desktop evidence includes native-enabled dialogs driven through Qt, out-of-bounds
  pointer events and loss-of-grab regressions, and controlled physical-output
  placement. Physical compositor drag, sleep/resume, additional drivers, trackpad
  gestures and accessibility acceptance are still required by the relevant
  foundation/hardening entries. No compositor settings were changed.
- Original mockups remain design references. The current shell hides unavailable
  assistant/recovery/render workflows; it does not simulate them.
- SKP/DWG research has explicit gaps. The Core editor can progress independently;
  the conditional compatibility delivery entries cannot claim completion without
  the required vendor support/licenses and corpus.

No unresolved architectural issue from these bounded experiments prevents M1.
Any later failure that invalidates a selected assumption must reopen the decision
with measured evidence rather than weakening a feature's acceptance criteria.
