room creation 3/3 and unsupported-operation handling 3/3; resize was 1/3 with

the final native 16-turn / 262,144-total-token / five-minute subscription profile:
**3/3 independently verified**, 10/12/14 turns, 98,807/121,570/149,877 reported
tokens, and 69.714/81.113/101.483 seconds. Earlier failures remain recorded and are
not counted as successful results. Token counts include cached input, not billing
cost; no billing amount was available.

The manual-target trials exposed two real gaps: no ordinary instance-only member
edit, and a 60-second draft default shorter than the assistant task. Both are
corrected with explicit scope/authorization and bounded lifetime tests. The
passing trial uses inspected vertex IDs and ordinary transforms without recipe
metadata. Metadata-free window recognition is demonstrated for this fixture,
not asserted for arbitrary imported or malformed assemblies.

native runs instead of the opt-in skipped CTest. Scope and orchestration pass
