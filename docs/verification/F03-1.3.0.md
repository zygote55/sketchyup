# F03 terrain and site tools: 1.3.0 release record

Date: 2026-10-21. **The release record is complete at the 1.3.0 release candidate
`d69c4402268fef7e78de5cced7496f12091f52ea` (RC3), and SketchyUp 1.3.0 is published.** On
2026-10-22 the owner approved the tag and the release, accepted the remote corpus gate (R086.g)
carried from RC1, and accepted that the native and dialog-audit cells that no CI line runs stay
recorded as not run. The annotated tag `v1.3.0` points at the RC, and the
[GitHub release](https://github.com/zygote55/sketchyup/releases/tag/v1.3.0) attaches the six files of the artifact manifest; see
[Published release](#published-release). This record, as first merged in
[#409](https://github.com/zygote55/sketchyup/pull/409), said it awaited the tag; it is updated
here to the outcome.

All ten CI jobs of the full tier pass at the RC. The local walkthrough (artifacts, package acceptance, and the pinned, fresh and Qt 6.8 reference clean machines) passes at RC3 on the first attempt; it was narrowed for 1.3.0, and the native cells that no CI line runs were not run. The provider corpus passes (R086.g, corpus v5, 24/24, no blockers), from the
owner-approved run at RC1, relied on unchanged at RC3 because every task's first request is
byte-identical. The triage finds no release-blocking and no Major defect open. The hardware checks
and the manual pass that [ADR 0161](../decisions/0161-m9-hardware-evidence-waiver.md) waives were
not run. They are marked **Waived (ADR 0161)** below and stay **untested**; they are not claimed to
pass.

The procedure is [M10 acceptance](../M10_ACCEPTANCE.md), "Required evidence at the RC" and
"Release record". The record follows the 1.2.0 record, [F02-1.2.0](F02-1.2.0.md).
[Machine-readable summary](F03-1.3.0.json). Records written after the RC, this one included, are
evidence about the RC and are not part of its artifacts.

- `pacman -U` upgrades 1.2.0-1 to 1.3.0-1 and keeps preferences. Package acceptance checks the
  upgrade from a 1.2.0-1 package built from the release source, and the clean machines repeat it
  from the published 1.2.0-1 (the reference machine from its reference-built 1.2.0-1) with
  shortcut bindings.
- 1.3.0 writes schema 29 only for documents with a terrain or a site origin, and 28, 27 or 26
  otherwise. The published 1.2.0-1 CLI refuses a schema-29 file unchanged (`terrain_io` in the
  package `check()`) and opens schema-28 files written by 1.3.0 (`component_parameter_io`); on the Qt 6.8 reference, 1.2.0-1 refuses the schema-29 save unchanged and 1.1.1-1 refuses schema 29 and 28 unchanged.
  32 historical fixtures migrate with the installed CLI.
- Rollback installs the 1.2.0-1 package. Documents without a terrain or site origin open in 1.2.0;
  documents with one do not. `NAME.sketchyup.bak` keeps one previous save.
