PRs #14–#19 are merged. Thirteen development suites and nine Qt-free sanitizer
suites pass locally. Geometry limits are explicit and enforced: finite planar
arrangements and bounded sweeps are supported; arbitrary 3D booleans, crossing
multiple opposite faces and nonprismatic inward intersections are not implied.
The file format remains experimental, and durable remote outcomes remain absent.

The viewport exposes persistent IDs, and numeric push/pull uses the new core.
Full drawing tools, unit syntax, inference and selection UX are M3 work. Picking
remains linear and geometric operations use documented resource budgets; this gate
does not claim the M9 large-scene performance target. Existing physical-device,
accessibility and deployment/release acceptance boundaries remain in force.
