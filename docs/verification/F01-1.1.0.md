## Unresolved limits

- **Waived and untested (ADR 0161):** Intel campaigns and the sharing-off memory control,
  X11 output hotplug, suspend/resume, a physical 150% output, physical pointer capture, input
  methods, D-020 on Hyprland, automatic X11 output placement, an interactive Orca session and
  the manual walkthrough on the installed RC. They stay **untested**, not passed. The owner
  covers them in daily use.
- **Not run at the RC by the owner's trim:** the local sanitized build and its 138 non-CI
  sanitized native cells. The CI sanitize job passed.
- **D-036:** on Qt 6.8.0, sheet PDF export writes a malformed Info dictionary (Minor, open,
  Qt 6.8 only; fix in 1.1.1). Poppler cannot read the document's title, creator, producer or
  dates. Pages, text, fonts and the attached report are intact. The measured PDF export uses
  `QPdfWriter` the same way and was not checked.
- **Advanced token headroom:** 6,819 tokens (about 2.6%) in the worst R086.cd run. One more
  provider turn in a 12-turn Advanced run would exceed the budget.
- **Schema validator ignores `anyOf`.** The shared request validator does not evaluate
  `anyOf` (used by reference-image and text updates), as [R090.e](R090e-drawing-sheets.md)
  records. Not in the open-defect list.
- **D-034:** the unreproduced Wayland `render_input_tests` hang (Minor, open).
- **D-032:** fractional focus rings below 3:1 at 1.5× (Minor, open, disclosed).
- **Make component and edge-split lineage.** Paper dimensions and labels anchored to
  geometry that is split or made into a component break where model annotations survive;
  **Reattach** repairs them ([R091.h known limitations](R091h-sheet-layout.md#known-limitations),
  [ADR 0164](../decisions/0164-sheet-layout-interface.md)). Disclosed in the release notes and
  support matrix.
- **Model workspace icon-strip breakpoint not implemented.** [UX_DESIGN.md](../UX_DESIGN.md)
  collapses the side panel to an icon strip between 800 and 1100 px; the Model workspace does
  not. Not in the open-defect list.
- **Open Minor defects and Limitations:** as in the triage table above.
- **Provider:** acceptance covers one remote configuration and the frozen tasks only. Local
  profiles stay experimental (ADR 0160).

## Upgrade and rollback

[RELEASE_NOTES.md](../RELEASE_NOTES.md#upgrade-from-101-1) is the user-facing source. At the
RC:

- `pacman -U` upgrades 1.0.1-1 to 1.1.0-1 and keeps preferences. Package acceptance checks
  this, and all three clean machines repeat it with shortcut bindings (the Qt 6.8 reference
  from a 1.0.1-1 package built on its archive).
- 1.1.0 writes schema 27 only for documents with sheets, and schema 26 otherwise. The
  published 1.0.1-1 CLI refuses a schema-27 file unchanged and opens a sheet-free file saved
  by the RC package ([ADR 0163](../decisions/0163-documentation-sheets.md) downgrade window).
  30 historical fixtures migrate with the installed CLI.
- Rollback installs the 1.0.1-1 package. Documents without sheets open in 1.0.1; documents
  with sheets do not. `NAME.sketchyup.bak` keeps one previous save.
