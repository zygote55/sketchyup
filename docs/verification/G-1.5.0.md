## Versions and format

The release notes ([Versions](../RELEASE_NOTES.md#150)) and the support matrix state the versions. In
short: `sketchyup` 1.5.0-1 and `sketchyup-ifc` 1.5.0-1; the native document is schema 34 at most, in
SKUPDOC container version 2, and reads versions 1 through 34; saves record the writer `SketchyUp/1.5.0`.
The MCP, inspection, transaction, recipe and other public schemas are unchanged from 1.4.0. The release adds
no third-party code: the GeoTIFF reader uses the inflater of miniz, which 1.4.0 already ships.

A document with no GeoTIFF terrain is written exactly as 1.4.0 writes it. A GeoTIFF terrain is written at
schema 34, which 1.4.0 refuses.

- A document with a GeoTIFF terrain does not open in 1.4.0. Copy such a document before you open it in 1.5.0 if you may need 1.4.0.
