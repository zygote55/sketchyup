# Native dialog Tab traversal

The native accessibility fixture now sends Tab through the Drawing plane, Keyboard shortcuts, Commands and model search, and all four synthetic Assistant provider/authentication preference modes in both themes. It inventories every visible, enabled Tab-focusable public control, coalesces composite internal editors with their public controls, requires each Tab focus owner to remain inside the owned dialog, and verifies every inventoried control is reached. The document's canonical bytes remain unchanged. No Apply, document-changing action, real credential helper or provider request is activated.

Tested source `673525ba678dfd34a9756e8b0c33e587c4a082b6` depends on PR250's dialog names. All four normal and four ASan/UBSan cases passed with leak detection: native X11 and isolated Wayland, each at scale1 and2. Every case covers14contexts, with zero unnamed or unreachable controls. The frozen25-input reuse overlay and private sizing exceptions are retained in the source record; they do not change production limits. Caches were restored, two compiler jobs/eight fixed CPUs/four GiB RAM/no added swap were retained, and scratch stayed on persistent disk. Sanitizer Wayland runs use the SHA-identified CI client-library correction recorded in the freeze; no suppression is used.

The original normal campaign passed X11scale1, then failed the Wayland focus invariant before any Tab event. A separate trace-only replay retained that failure and recorded `drawingPlaneDialog` at step0, with Qt marking it active while actual widget focus remained on the main-window command-search button. The fixture now waits, within Qt's bounded readiness helper, for the owned dialog's widget focus transfer before starting traversal. It does not force a widget focus, skip a control, lengthen the overall native deadlines or weaken the per-Tab invariant. Both original results and their source identities remain separate artifacts.

This qualifies the stated QtTest/native dialog traversal scope. Whole-application keyboard interaction, physical keyboard/IME behavior, external AT-SPI screen-reader use, visual contrast and text-scale acceptance still require their own evidence; R084 and M9 remain open.
