## Upgrade and rollback

[RELEASE_NOTES.md](../RELEASE_NOTES.md#install-and-upgrade) is the user-facing source. In
short:

- `pacman -U` upgrades `0.1.0-3` to `1.0.0-1` and keeps preferences. Package acceptance at
  the RC checks this, and three clean machines repeat it with shortcut bindings.
  `check()` ran 190/190 on the RC source built as `0.1.0-3`, and `1.0.0-1` was rebuilt
  from that same source with `--nocheck`; the application version comes from CMake
  `project()`, not from `pkgver` (`packaging/arch/verify-package.sh`).
- 1.0.0 reads document versions 1–26 and writes 26. `sketchyup-cli --migrate-native` writes
  to a new path and never converts in place. 28 historical fixtures migrate at the RC.
- Install a package built for the system's repository snapshot, because the dependencies
  carry no versions (D-029).
- [Rollback](../RELEASE_NOTES.md#rollback) goes to a 0.1.0 development build. A build older
  than schema 26 rejects 1.0.0 documents and leaves them unchanged. The previous save stays
  in `NAME.sketchyup.bak` for one save. Removing the package leaves documents and
  preferences in place.
