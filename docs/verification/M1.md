Wayland tests use the development machine; package acceptance uses disposable Arch
and llvmpipe/Xvfb. The UI saves synchronously, picking remains linear, and retained

format or advanced modeling feature is implied by this gate. The reserved file
epoch is `1`, and unsupported assets/features are rejected. Physical suspend/resume,
additional graphics drivers, actual trackpad gestures and accessibility acceptance
remain the documented device/hardening matrix. Context recreation, synthetic input
and the tested display scales have their own bounded evidence.
