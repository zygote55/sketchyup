## Integrated room study

`m4_workflow_tests` builds a 6 × 4 m room with 200 mm walls, 2.7 m height and two
1.2 × 1.0 m through openings at a 900 mm sill. Native rectangle/Measurements,
selection/delete and push/pull paths construct the walls and openings. The closed
wall volume is verified as 9.888 m³. Window geometry/materials/assets are assembled
through the same public core operations used by command adapters; native group,
component, nested context and transform paths create and edit two instances.

The window dimensions refer to the outer frame. Each frame has 80 mm rails and
an inset glass panel. A shared nested frame-depth edit propagates to both windows
while glazing and room walls remain unchanged. Native make-unique separates one
definition, and a subsequent edit changes only that frame. The final depths are
300 mm for Window A and 200 mm for Window B; this fixture tests depth/isolation,
not the M5 AI request to widen a window while updating its opening.

The native model retains millimeter display units, separate frame/glass materials,
glass opacity, window tags, nested groups, two component definitions/instances,
an owned notes asset and an explicitly missing glass texture. Menu Undo, keyboard
Redo and History navigation agree and return to the explicitly saved state.
Save/reopen preserves the exact serialized room snapshot and identities.

The recovery check starts a separate live writer process, waits for its durable
checkpoint acknowledgement, kills it, then verifies the recovered snapshot and
stale-lock release. The original explicit save remains byte-for-byte unchanged.
The native recovery dialog opens the unsaved room as dirty with no fabricated
history. Canceling close preserves it. Saving writes a new copy and retires the
recovery image without overwriting the source. Unsaved-dialog outcomes now require
an explicit Save or Discard; a nonstandard dismissal defaults to preserving work.

The [recorded model](../../examples/m4-room-study.sketchyup) is the generated,
recovered final room. It is a native schema-12 demonstration fixture, not a foreign
format or an original-prototype runtime. [X11 capture](M4-room-x11.png) and
[actual Hyprland capture](M4-room-hyprland.png) were inspected for geometry,
nested Outliner hierarchy, saved status and visible unit labels.

## Boundaries

The finite planar/push-pull geometry limits remain. This checkpoint does not add
general solid booleans, arbitrary self-intersection repair, UV texture rendering,
AI providers or Blender handoff. Missing resources are preserved and surfaced.
The M9 hardware, accessibility, large-scene and release matrix remains separate.

Final X11 History, Info and organization regressions also pass after the tiled-
window test adjustments. The recorded room opens through the headless CLI.
