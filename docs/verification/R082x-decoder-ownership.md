# Fresh native-body ownership

Native decoding formerly deep-copied body records immediately after constructing them from validated file data. The decoder now passes only its freshly allocated body map through a private access bridge. Public `restoreRecords` still freezes caller-owned records by copying them, and validation, legacy topology conversion and atomic publication share the existing implementation. The bridge is private to the decoder translation unit; no public ownership-transfer API or sizing limit changes.

Tested source: `051d1d3e2c623fca025751bf67c4815ce87cf2d1`, based on PR249. The frozen reuse qualification checked all 305 compiled runtime inputs with seven disclosed overlays. All 38 normal and 38 ASan/UBSan cases passed with leak detection, including caller mutation isolation, legacy topology isolation, rejection without partial publication, native persistence/recovery, components, transactions and file-backed scene records. The cache source was restored. Raw logs, source hashes and the terminal result are retained alongside this record.

The controlled Release comparison used the same canonical 70,248,107-byte million-triangle native file, six durable byte-exact saves, and identical private sizing in both variants. The control switches only the decoder bridge from adoption to copying. Three sequential warm control runs preceded three sequential adoption runs; no cold-cache or UI responsiveness claim is made. Control opens took 5.84–5.93 seconds; adoption opens took 5.67–5.73 seconds. Saves took 4.12–4.20 seconds, and sampled process peak RSS remained about 1.82 GB. Both variants still miss the unchanged five-second open target. Three observations do not qualify a percentile or a general performance guarantee.

The operational container kept four GiB RAM, no extra swap, eight fixed CPUs, two compiler jobs, persistent disk scratch and a 300-second per-operation diagnostic timeout. The private million-triangle fixture does not establish public support at that size. Current-source integrated file responsiveness, cold behavior and the full R082/M9 release gate remain open. [Machine-readable identities and hashes](R082x-decoder-ownership.json) retain the distinction between the semantic regression campaign and the private warm comparison.
