## Owner trim of the local walkthrough

On 2026-10-15 the owner trimmed the local walkthrough so that it does not repeat what CI
runs at the RC. CI run [38780023627](https://github.com/zygote55/sketchyup/actions/runs/38780023627)
on `251fd52d` passed all four jobs. It is the evidence for every native line, `ctest`
step and sanitize step that the workflow runs.

- **Ran locally:** the release artifacts, package acceptance, the clean machines (pinned
  and fresh, with a sheets smoke), the native cells that CI does not run, the dialog-audit
  cells that CI does not run, the sheet-suite cells at 1.5, the M5–M8 studies, and the
  `sheet_export`/`sheet_export_real` detail for R092.d.
- **Covered by CI run 38780023627, not repeated locally:** `ctest --preset dev` (200/200),
  the opt-in `*_real` consumers (Blender 9/9, DXF 1/1, PDF 2/2), MCP schema validation,
  shipped recipes, generated reference and API schema checks, every native line of
  "Native interaction and OpenGL tests" and "Isolated Wayland interaction and rendering"
  (313 lines), the AT-SPI bridge on both backends at 1× and 2×, keyboard layouts, the
  fractional cells, the CI dialog audit (inventory, X11 2× and Wayland 1×), M5 with
  Blender, the headless recipe step, every step of the sanitize job (64/64, 104/104, 7/7,
  1/1 and its 46 native lines), Blender interoperability, and the CI package acceptance.
- **Stopped on purpose:** the local development job (`rc110-dev-build`) finished its
  build (exit 0) and was stopped at 11:38 during `ctest --preset dev`, at test 14 of 200,
  when the trim arrived. That stop is not a failure. Its build tree was used for the local
  runs below.
- **Not run locally:** the sanitized build, and so the 138 sanitized cells that are not CI
  lines (X11 at both scales and Wayland 1×). The 1.0.0 walkthrough ran them. The owner's
  trim skips sanitize when the CI sanitize job passes.

`docs/M10_ACCEPTANCE.md` is unchanged for 1.1.0, because the package ships it. It will be
updated for the trim after the release.

## Runs and limits

- **Wide runner** (a copy of `scripts/run-container-check.sh` outside the repository, SHA-256
  `63ec7b75…62d55c7d6`: six CPUs 6–11, 10 GiB, no extra swap, `-j4`, a 10 GiB free-memory
  precondition, `--cap-add=SYS_PTRACE` as the CI jobs have for `test-deadline.sh`). It ran
  package acceptance, the development build, the native cells, the audit, the studies and the
  R092.d detail, one container at a time.
- **Clean machines.** These used the R087.u method. Two CPUs, 2 GiB, no network, one at a time.
- **Packages in the native image.** Each job installed `native.yml`'s CI package set
  (without Blender), plus `xorg-setxkbmap` and `git`, from the pinned 2026-10-02 archive.
  So at-spi2-core and Poppler came from that archive, and no host files were mounted. The
  sheets-smoke PDFs were checked with the host's Poppler 26.08.0.
- **Source tree.** The native jobs used `git archive` of the RC commit. The tree has no
  `.git`, so the M5 and M6 `sourceCommit` fields record as null.

Large logs and evidence are in `~/sketchyup-verification/rc-1.1.0/` and are not
published. The JSON record lists the SHA-256 of each one it cites.

This record does not cover the manual user-guide pass or the hardware checks. ADR 0161
waives both. It does not change application code, fixtures or the build image.
